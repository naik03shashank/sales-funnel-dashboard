# 📊 Sales Funnel Conversion Intelligence Dashboard

A high-performance, premium BI dashboard designed to track leads through the entire sales lifecycle—from initial contact to closed revenue. This platform provides real-time insights into conversion rates, regional performance, and financial trends.

Live Demo: [https://sales-funnel-dashboard.onrender.com/](https://sales-funnel-dashboard.onrender.com/)

---

## ✨ Key Features

### 🚀 Sales Funnel Visualization
- **Dynamic Funnel Chart**: Real-time visualization of stage-by-stage attrition (Leads → Opportunities → Wins).
- **KPI Command Center**: Instant visibility into Total Leads, Win Rates, and Actual Revenue.
- **Trend Analysis**: Interactive area charts showing monthly lead generation vs. revenue growth.

### 📈 Advanced Regional Analytics
- **Performance Breakdowns**: Pie charts and bar graphs comparing North America, Europe, and Asia.
- **Efficiency Metrics**: Deep-dive tables showing conversion percentages and regional revenue contribution.

### 📋 Lead Management System
- **Full Database Access**: A high-density table view of every lead in the pipeline.
- **Lifecycle Tracking**: Precise dates for lead creation, opportunity status, and closing.
- **CSV Export**: One-click functionality to download the entire database for external reporting.

## 🛠️ Technology Stack

- **Frontend**: React (Vite)
- **Visualization**: Recharts (D3-based)
- **Styling**: Premium Glassmorphism UI (Vanilla CSS)
- **Icons**: Lucide React
- **Analytics**: SQL-ready data structure for Power BI/Tableau integration

## ⚙️ Local Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/naik03shashank/sales-funnel-dashboard.git
   ```
2. **Navigate to dashboard**:
   ```bash
   cd dashboard
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Run Development Server**:
   ```bash
   npm run dev
   ```
