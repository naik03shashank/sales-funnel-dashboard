# Sales Funnel Dashboard (React Frontend)

This is the React-based frontend of the Sales Funnel Intelligence Dashboard.

## Features
- **Dashboard**: Funnel summary and revenue trends.
- **Analytics**: Regional performance breakdown.
- **Leads**: Master database management.
- **Settings**: System configuration and CSV export.

## Deployment
This app is optimized for deployment on Github Pages and Render.

- **Build**: `npm run build`
- **Deploy to GitHub**: `npm run deploy`
